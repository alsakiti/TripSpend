TripSpend v6.4 update

1. Extract TripSpend-v6.4-update.zip.
2. Upload EVERYTHING inside it to the root of your existing TripSpend GitHub repository.
3. Replace existing files and commit.
4. Wait about 1–2 minutes.
5. Completely close TripSpend.
6. Reopen it while online.
7. Confirm the visible badge says v6.4.

IMPORTANT:
Your existing trip is migrated automatically.
Do NOT delete browser data before opening v6.4 for the first time.

After opening v6.4:
Settings → Data safety
should show INDEXEDDB when the primary database is active.

TripSpend automatically creates restore points including:
- Latest
- recent daily snapshots
- Before v6.4 upgrade

If IndexedDB is unavailable, TripSpend switches to SAFE FALLBACK instead of losing your trip.
