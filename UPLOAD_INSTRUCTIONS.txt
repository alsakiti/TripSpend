TripSpend v5.0 update

1. Extract TripSpend-v5-update.zip.
2. Upload EVERYTHING inside to the ROOT of your existing TripSpend GitHub repository.
3. Replace files with the same names.
4. Commit the changes.
5. Wait 1–2 minutes for GitHub Pages.
6. Completely close the TripSpend Home Screen app.
7. Reopen it while online.
8. Confirm that the visible badge says v5.0.

New in v5.0:
- Multiple countries with dates, currency and destination budgets
- Trip planner with planned/upcoming costs
- Actual + upcoming = committed trip cost
- Paid By and Expense For on expenses
- Multi-person expense splitting
- Automatic group settlement (who owes whom)
- Expenses can be assigned to a country
- Existing v4 data remains compatible

If the old version appears, open the GitHub Pages URL in Safari, refresh once, then reopen the Home Screen app.
