TripSpend v5.5 update

1. Extract TripSpend-v5.5-update.zip.
2. Upload EVERYTHING inside it to the root of your existing TripSpend GitHub repository.
3. Replace existing files and commit.
4. Wait 1–2 minutes for GitHub Pages.
5. Completely close the Home Screen app.
6. Reopen TripSpend while online.
7. Confirm the visible badge says v5.5.

The New Trip flow is now:
Trip name
→ Countries (Country 1 + its dates/currency)
→ + Add another country (optional)
→ Total trip budget
→ Travelers
→ + Add traveler (optional)
→ Home currency
→ Create Trip

There is no separate "route" concept anymore. Overall trip dates are calculated automatically from the country dates.
