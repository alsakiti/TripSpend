TripSpend v6.3 update

1. Extract TripSpend-v6.3-update.zip.
2. Upload EVERYTHING inside it to the root of your existing TripSpend GitHub repository.
3. Replace the existing files and commit.
4. Wait about 1–2 minutes for GitHub Pages.
5. Completely close TripSpend.
6. Reopen it while online.
7. Confirm the visible badge says v6.3.

Main visual changes:
- Settings → Appearance: Auto / Light / Dark
- New SVG bottom navigation with Home, Expenses, Plan, Analytics, Settings
- Floating Add Expense button
- Cleaner typography and cards
- Trip country flag rail
- Subtle animations and ✓ Saved feedback
- Better empty states
- Amber/red budget warnings only when meaningful

No trip, expense, traveler, plan, rate, or settlement data is removed.
