TripSpend v6.8.3 — MANUAL GITHUB UPLOAD

1. Unzip this file on your phone/computer.
2. Open your GitHub repository: alsakiti/TripSpend.
3. Make sure you are on the main branch and at the ROOT of the repository.
4. Choose Add file -> Upload files.
5. Upload the FILES INSIDE this folder (and the icons folder), replacing matching files.
6. Commit the upload to main.
7. Wait for GitHub Pages deployment to finish.
8. Fully close the TripSpend Home Screen app and open it again while online.

IMPORTANT:
- Do NOT clear Safari/site data.
- Do NOT delete the Home Screen app while recovering local trip data.
- This package does NOT deploy or change your Cloudflare Worker. Your existing Worker remains separate.

INCLUDED IN v6.8.3:
- English / Arabic dashboard language switch.
- Arabic RTL layout and expanded Arabic UI translations.
- Arabic-capable TripSpend AI UI (the Cloudflare Worker must also support Arabic).
- Expanded AI action client: add/edit/delete expenses, plans, itinerary, travelers, countries, settlements, trip edits, budgets, and undo.
- Confirmation remains required before AI changes are saved.
- iPhone AI input stays at 16px to prevent Safari focus zoom.
- Home Screen startup protection: IndexedDB operations now time out safely instead of leaving the app on “Loading your trip…” forever.
- If Home Screen storage does not respond, TripSpend shows a Retry option without deleting the database.
