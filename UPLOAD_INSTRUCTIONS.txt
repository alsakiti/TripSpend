TripSpend v6.0 update

1. Extract TripSpend-v6.0-update.zip.
2. Upload EVERYTHING inside it to the root of your existing TripSpend GitHub repository.
3. Replace the old files and commit.
4. Wait about 1–2 minutes for GitHub Pages.
5. Completely close the TripSpend Home Screen app.
6. Reopen it while online.
7. Confirm the visible badge says v6.0.

Home is intentionally much simpler now:
Current country → Remaining → Safe today / Spent today → Add Expense → Countries → Next destination → Trip status.

Currency converter moved to Settings.
Detailed expense history remains in Expenses.
Who owes whom and charts remain in Analytics.
