TripSpend v5.1 update

1. Extract TripSpend-v5.1-update.zip.
2. Upload EVERYTHING inside to the root of the existing TripSpend GitHub repository.
3. Replace existing files and commit.
4. Wait 1–2 minutes for GitHub Pages.
5. Completely close TripSpend and reopen it while online.
6. Confirm the version badge says v5.1.

How to add multiple countries after this update:
Settings → + Add another country
or
Home → Trip plan → Open planner

Then choose the country, dates, local currency and optional country budget, and tap Add Country.
