TripSpend v5.6 update

1. Extract TripSpend-v5.6-update.zip.
2. Upload EVERYTHING inside it to the root of your existing TripSpend GitHub repository.
3. Replace existing files and commit.
4. Wait 1–2 minutes.
5. Completely close TripSpend and reopen it while online.
6. Confirm the version badge says v5.6.

New:
- Added countries now have Edit + Remove.
- Added travelers now have Edit + Remove.
- Country 1 is edited directly in its visible fields.
- The first traveler is edited directly in the Your name field.
- Invalid From/To date combinations are corrected automatically.
