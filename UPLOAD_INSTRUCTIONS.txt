TripSpend v4.2 update

1. Extract TripSpend-v4.2-update.zip.
2. Upload every file/folder inside it to the ROOT of your existing TripSpend GitHub repository.
3. Replace files with the same names.
4. Commit the changes.
5. Wait about 1–2 minutes for GitHub Pages.
6. Open TripSpend and refresh twice if the old cached version appears.

v4.2 fixes the oversized iPhone setup layout, date-field overflow, and Install App behavior.
