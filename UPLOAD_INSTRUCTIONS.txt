TripSpend v6.6.9 update

1. Extract TripSpend-v6.6.9-update.zip.
2. Upload EVERYTHING inside it to the root of your TripSpend GitHub repository.
3. Replace existing files and commit.
4. Wait about 1–2 minutes.
5. Completely close TripSpend.
6. Reopen it while online.
7. Confirm the badge says v6.6.9.

Main improvements:
- 1,000.000 OMR displays as 1,000 OMR
- 0.000 OMR displays as 0 OMR
- Real OMR fractions keep all 3 decimals
- Cleaner percentages
- Large monetary values resize to fit
- Better numeric alignment
- Slightly quieter Budget / Spent values
- FX rate precision unchanged
- No calculation or data migration
