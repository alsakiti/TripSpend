1. Extract TripSpend-v6.6.3-update.zip.
2. Upload EVERYTHING inside it to the root of your TripSpend GitHub repository.

- Portable JSON backups now include receipt photos
- Settings shows storage/receipt usage
- Clean unused receipt files safely
- Settings shows Current/Latest app version
- Check for Update + Refresh App
- Shared expenses preview the per-person split before saving

Your existing trips, expenses, receipts, Past Trips, settlements and backups are preserved.
